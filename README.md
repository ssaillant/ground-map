# Ground Map

A machine-checked map of which combinations of principles from the logic of
metaphysical ground are jointly consistent. Sources: Fine 2010, 2012; Krämer 2013;
Correia 2014; Woods 2018; Korbmacher 2018; Fritz 2022; deRosset and Fine 2023,
with more listed in the registry bibliography.

Every point in the lattice of principle strengths is classified as

- **refuted**, with a checked Isar proof;
- **finite-model**, with a finite model checked independently;
- **infinite-model**, with an infinite model built in Isabelle (decision D4);
- **unknown**, which includes every timeout. A timeout is never "consistent".

Version 1 uses Isabelle/HOL only.

## Layout

| Path | Contents |
|---|---|
| `principles/registry.yaml` | Principle families and strengths, source formulations with page references, formal statements, reading choices, decisions D1–D4, puzzle targets, findings, bibliography |
| `isabelle/` | Isabelle session `Ground_Map_Checks`: signature and checked puzzles |
| `results/` | Machine output of the enumeration (step 4; empty for now) |
| `docs/` | Generated by CI from `results/`. Do not edit by hand. |
| `AI_USE_LOG.md` | Prompts, models and human review, for AI-use disclosure |
| `TOOLS.md` | Pinned tool versions |

- Finding F1: packages with CL.PROP, TRANS.P and IRR.F plus any of CONJ.BIN,

  Elgin 2026) are listed in the registry, not yet encoded.

## Rules

Nothing reported as done may contain `sorry`, `oops` or extra axioms
(`axiomatization`). CI enforces this with `scripts/check_no_sorry.sh` and builds
the session with the pinned Isabelle.

## Build locally

    isabelle build -v -D isabelle
