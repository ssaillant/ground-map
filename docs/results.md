## How to read this page

A *package* is a set of registry principles, always together with factivity (FACT). Each package is classified as

- **refuted**: Isabelle has checked a proof that the package is inconsistent;
- **refuted at N1**: Isabelle has checked a proof that the package is inconsistent with N1 (at least one grounding fact), and no refutation of the package itself was found. This is not a consistency claim. Where the row says *model at N0 verified*, a model of the package in which nothing grounds anything was found by Nitpick and re-checked by the independent implementation; otherwise the package without N1 is unknown. (Until registry 0.3.0-draft this class was called trivial-only and was described as consistent without a model; audit finding A3.);
- **finite-model**: a finite model with at least one grounding fact (N1), either found by Nitpick and re-checked by an independent implementation of the semantics, or built and checked in Isabelle (`isabelle/Model_Certificates.thy`, `isabelle/Restricted_Models.thy`, section 4);
- **infinite-model**: an infinite model built and checked in Isabelle (decision D4);
- every model has a certificate kind (decision D7): *nitpick+python* (found by Nitpick, re-checked by `scripts/verify_models.py`) or *isabelle-kernel* (built and proved in Isabelle). The class does not depend on the kind;
- **unknown**: no proof and no model within the time limits. Unknown never means consistent.

A refutation of a package refutes every stronger package; a model of a package is a model of every weaker one. "Stronger" uses only the implications proved in `isabelle/Order.thy`. Every entry is standalone: a package contains exactly the entries listed, and an entry's rank in the registry is a label, not an inclusion.
